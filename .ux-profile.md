# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Refined typography, balanced depth, elegant data tables, high clarity. RedactSearch is a compliance-style review tool: dense but calm, hairline borders before shadows, one interactive colour (pen blue), the marker highlight reserved for cited turns, and solid ink redaction marks as the signature element. Typeface: Atkinson Hyperlegible Next. Tokens live in `web/src/styles/tokens.css`.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata (split, source and similar facts are plain text)
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text, 3:1 for large text, borders of controls and focus indicators, in light and dark themes
- **Touch / focus:** 44×44px minimum touch targets; 2px focus ring at 2px offset in `--focus`, visible in both themes; full keyboard operation

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Precise and invisible. Verb-first buttons that say what happens ("Upload and redact", "Open full call"). Errors state what happened and how to fix it, never apologise. Say "redacted", "call", "turn" consistently; never "PII" in UI copy aimed at reviewers.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (web/package.json); import named icons, `aria-hidden` unless the icon is the only label
- **Notes:** Replaces the earlier hand-drawn inline set. 16px in controls, 18px in navigation, stroke 2.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
